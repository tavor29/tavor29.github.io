# Site notes

Static Astro portfolio with Tailwind v4 (token-mapped, preflight off) and GSAP. The design system, including tokens, type, icons and motion, is in `docs/DESIGN.md`. Project-wide rules are in `../CLAUDE.md`. See also `README.md` and https://docs.astro.build.

Use the tokens, the `Icon` component and the `components/ui/*` primitives for anything new. Framework islands or state libraries are allowed when a feature needs them; say why before adding one.
